# Apache Hadoop Docker Setup

Multi-node Apache Hadoop cluster running on Docker for local development and learning.

## Quick Start

```bash
./start.sh
```

## Components

- NameNode + DataNodes (HDFS)
- ResourceManager + NodeManagers (YARN)
- Web UIs for monitoring

## Tech Stack

- Apache Hadoop 3.x
- Docker and Docker Compose
- Shell scripts for cluster management
